## LPass Password Manager

Lightweight, easy-to-use CLI password manager written in C++

# Features

* Truly Random Password Generation using [hardware devices.](https://en.cppreference.com/cpp/numeric/random/random_device)
* No installation required, only needs write permissions to save the vault to a file.
* Simple to learn and use.
* Strong AES-256 encryption.
